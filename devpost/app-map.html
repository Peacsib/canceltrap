2. Code Tour & Key Stops

Stop 1: The Upfront Contract — src/lib/types.ts

Defines SubscriptionDefusalResponse, specifying exactly what Gemini must return: merchant details, 5-year vampire bleed, detected deceptive trap, step-by-step checklist, and kill-switch timestamps.

Stop 2: Multimodal Gemini 3.8 Flash Route — src/app/api/analyze/route.ts

Uses @google/genai on the server with responseMimeType: "application/json". Validates base64 receipt screenshots, infers relative renewal deadlines, and handles non-subscription uploads gracefully.

Stop 3: Interactive Defusal Dashboard — src/components/DefusalDashboard.tsx

Orchestrates MetricsGrid (4 top glass metric cards with Vampire Bleed), DefusalChecklist (interactive step checkboxes with decoy warnings), and ActionHub.

Stop 4: Zero-Dependency .ics Kill-Switch — src/lib/calendar.ts

Pure TypeScript RFC 5545 iCalendar generator that outputs standard VCALENDAR, VEVENT, and VALARM blocks, triggering a 1-click browser download of the alert.

3. "To Change This, Start Here"

Add a New Preset Trap Edit src/data/presets.ts and add a new entry to PRESET_SCENARIOS.
Modify Dark Pattern Prompts Adjust systemPrompt in src/app/api/analyze/route.ts.
Tune Glass Styling / Colors Adjust CSS variables in src/app/globals.css (e.g. --gradient-sky, --glass).
Change Kill-Switch Reminder Time Edit alertMinutesBefore in src/lib/calendar.ts.

4. A Practice to Reuse

The Upfront Rigid Contract Pattern:
By specifying the exact TypeScript interface (SubscriptionDefusalResponse) and enforcing it via Gemini's responseMimeType: "application/json" before touching frontend UI code, we eliminated ambiguous model responses, Markdown fence wrapping bugs, and unpredictable schema drift. In future AI agent projects, defining your JSON schema contract upfront guarantees deterministic UI rendering and clean failure states.
